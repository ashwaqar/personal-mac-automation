# Architecture

## Objective

Automate macOS file organization and maintenance.

## Workflow

Downloads
→ AutoArchive
→ TrashLater
→ Delete

## Components

- YAML Rules Engine
- Python Automation Engine
- LaunchAgent Scheduler
- Logging Layer
- Future AI Layer

## Security

Runs only within the current user context.
Uses Path.home().
No system-wide permissions required.
